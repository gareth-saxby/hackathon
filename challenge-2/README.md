# Challenge 2 — Government Document Search & Data Quality Tool

A Streamlit application for searching and assessing the quality of government documents. Built for the DSIT AI Engineering Lab Hackathon 2026.

## Requirements

- Python 3.12+

## Installation

### Using pip

```bash
cd challenge-2
pip install -r requirements.txt
```

### Using uv (recommended)

```bash
cd challenge-2
uv sync
```

## Running the application

```bash
streamlit run app.py
```

The app will be available at `http://localhost:8501`.

## Running tests

```bash
pytest
```
